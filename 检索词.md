# AI4S 检索词

## 检索设计

数据库为Web of Science Core Collection，范围为2010—2026年，语言为English，文献类型为Article。检索工作于2026-10-18完成。

检索采用三条互补路径，以OR连接：

| 路径 | 检索内容 |
| --- | --- |
| 显式表述 | AI4S、AI驱动科学发现及自主实验室等表述 |
| 方法、任务与领域结合 | AI方法 AND 科研任务 AND 科学领域 |
| 科学机器学习 | Scientific Machine Learning等 AND 方程或物理约束 |

AI方法在标题或作者关键词中检索，科研任务在摘要中检索，领域词使用TS字段。TS覆盖标题、摘要、作者关键词和Keywords Plus；领域条件仅作用于第二条路径。

### 字段说明

| 字段   | 含义                                 | 本检索中的用途        |
| ---- | ---------------------------------- | -------------- |
| `TS` | Topic，覆盖标题、摘要、作者关键词和 Keywords Plus | 显式 AI4S 表述、领域词 |
| `TI` | Title                              | AI 方法词         |
| `AK` | Author Keywords                    | AI 方法词         |
| `AB` | Abstract                           | 科研任务词、PDE/物理约束 |
| `PY` | Year Published，WoS 原始出版年           | 限定 2010—2026 年 |
| `LA` | Language                           | 限定 English     |
| `DT` | Document Type                      | 限定 Article     |

> `TS` 与 `TI/AB/AK` 存在包含关系。方法词只放在 `TI` 或 `AK`，仅出现在摘要中的方法名称不会被重复抓取。
