# AI4S 检索词

## 检索设计

数据库为Web of Science Core Collection，范围为2010—2026年，语言为English，文献类型为Article。检索工作于2026-10-18完成。

检索采用三条互补路径，以OR连接：

| 路径 | 检索内容 |
| --- | --- |
| 显式表述 | AI4S、AI驱动科学发现及自主实验室等表述 |
| 方法、任务与领域结合 | AI方法 AND 科研任务 AND 科学领域 |
| 科学机器学习 | Scientific Machine Learning等 AND 方程或物理约束 |

AI方法在标题或作者关键词中检索，科研任务在摘要中检索，领域词使用TS字段。TS覆盖标题、摘要、作者关键词和Keywords Plus；领域条件仅作用于第二条路径。

## 政策依据

上述检索式的涉及到的领域词和科学研究任务词，主要参考了国内外权威的政策文件。如：[《国家重点研发计划颠覆性技术创新重点专项2025年度人工智能驱动的科学研究领域项目申报指引》](docs/policy/ai4s-policy-2025.pdf)（仓库内PDF存档；[官方发布页面：https://service.most.gov.cn/kjjh_tztg_all/20250515/5682.html](https://service.most.gov.cn/kjjh_tztg_all/20250515/5682.html)）。该指引涵盖前沿科学、生命健康、新材料和工程设计，提出将AI与理论推导、数值模拟和科学实验相结合，为本研究选择科研领域与任务词提供依据。数学、化工等细分词项再结合学科资助范围和代表性文献补充。

## 词项来源

检索式涉及到的领域词与具体的科学任务词均参考官方政策文件和美国的创世纪科学计划及学科资助范围，根据相关的官方政策和文件确定具体英文表达结合代表性文献和领域惯用语。

- **科学发现与科研任务**：参考[AI驱动科学研究项目申报指引](docs/policy/ai4s-policy-2025.pdf)、[“人工智能+”行动意见](https://www.mee.gov.cn/zcwj/gwywj/202508/t20250827_1126207.shtml)及[AI4S专项部署](https://kw.beijing.gov.cn/xwdt/kcyx/xwdtcyfz/202303/t20230328_3817948.html)，形成发现、预测、设计与实验等任务表达。
- **科学领域**：结合上述指引、[Genesis Mission](https://www.whitehouse.gov/presidential-actions/2025/11/launching-the-genesis-mission/)及其[科学技术挑战](https://www.energy.gov/undersecretaryforscience/articles/energy-department-announces-26-genesis-mission-science-and)，覆盖材料、物理、生命、能源与工程等领域。
- **数学**：参考[数学科学研究工作方案](https://www.cas.cn/zcjd/201909/t20190918_4715042.shtml)与[基金委数学科学处资助范围](https://www.nsfc.gov.cn/p1/2851/3082/3089/sxkxc.html)，并结合[AI引导数学研究](https://doi.org/10.1038/s41586-021-04086-x)、[大模型程序搜索与数学发现](https://doi.org/10.1038/s41586-023-06924-6)等文献，补充数学研究用语。
- **化学工程**：参考[石化化工行业指南](https://www.hunan.gov.cn/zqt/zcsd/202401/t20240126_32635403.html)与[基金委化学科学五处资助范围](https://www.nsfc.gov.cn/p1/2852/3164/3178/hxkxwc.html)，结合[化工机器学习](https://doi.org/10.1002/cite.202100083)、[机器人流动合成](https://doi.org/10.1126/science.aax1566)、[膜蒸馏设计](https://doi.org/10.1016/j.seppur.2023.124627)、[萃取蒸馏溶剂设计](https://doi.org/10.1016/j.jes.2024.08.014)及[膜蒸馏多目标优化](https://doi.org/10.1016/j.watres.2026.126093)等文献补充具体对象。
- **AI方法**：采用机器学习领域常用方法名称，包括神经网络、大语言模型、贝叶斯优化、主动学习、强化学习、扩散模型和科学机器学习等。
