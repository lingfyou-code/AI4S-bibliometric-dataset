# AI4S 检索词与来源

## 1 检索设计

数据库为Web of Science Core Collection，观察范围为2010—2026年，语言为English，文献类型为Article。检索工作于2026-10-18完成。

检索采用三条互补路径，以OR连接：

| 路径 | 内容 | 字段 |
| --- | --- | --- |
| 显式表述 | AI4S、AI驱动科学发现及自主实验室等 | TS |
| 方法、任务与领域结合 | AI方法 AND 科研任务 AND 科学领域 | (TI OR AK) AND AB AND TS |
| 科学机器学习 | Scientific Machine Learning等 AND 方程或物理约束 | TS AND AB |

TI为标题，AK为作者关键词，AB为摘要；TS涵盖标题、摘要、作者关键词与Keywords Plus。科学领域条件作用于第二条路径，其中包括数学12项、化工16项和其他领域42项，共70项。

## 3 词项来源

领域与任务范围参考官方政策及学科资助范围，具体英文表达结合代表性文献和领域惯用语确定。词项分别采用官方概念的标准译法、上位概念的语义转化和文献补充表达。

| 词项组 | 主要来源及对应内容 |
| --- | --- |
| AI4S与科学发现 | P1、P2、P6支持AI驱动科学研究与科学发现的研究范围；AI4S等采用常见英文表述 |
| AI方法与科学机器学习 | 采用机器学习领域常用方法名，如神经网络、主动学习、贝叶斯优化、物理信息神经网络及神经算子 |
| 科研任务 | P1、P2、P8中的发现、验证、设计、预测和实验活动，转化为科学发现、逆向设计、性质预测及实验规划等表达 |
| 材料、物理、生命、能源与工程领域 | P1、P3、P4界定主要领域范围，转化为材料、量子物理、生命科学、能源与先进制造等领域词 |
| 数学 | P5、P6提供学科与AI4S研究依据；P7提供微分方程、动力系统、图论、组合数学、数论、数值计算与反问题等学科范围；L1、L2补充AI参与数学研究的语境 |
| 化学工程 | P8、P9支持流动、传递、反应、过程强化与生物制造等方向；L3—L7补充过程系统工程、反应器设计、流动合成及具体蒸馏对象等用语 |
