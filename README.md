# AI4S-database：AI for Science 文献数据集

本仓库是AI4S文献计量研究的配套资料，公开检索式、筛选依据和样本的基本分布。


## 项目简介

AI4S-database 是一套基于AI4S研究的文献数据集，包含采用的检索式、候选文献数据等，可用于研究 AI 实质参与数学、自然科学与工程科学问题求解的演进路径与介入方式。

本项目可用于：

- **复用检索式**：在其他数据库中定位 AI4S 相关文献，或按同样逻辑改造检索式
- **简要计量分析**：年度产出、学科与期刊分布、关键词共现、机构合作等
- **方法参考**：把"AI 参与科研"操作化为可检索、可复核的条件
- **筛选方法借鉴**：可为其他研究，如何逐确定侯徐文献提供方法借鉴


## 研究背景

AI已用于蛋白质结构预测、材料与分子设计、数学发现和自主实验等科研任务，相关科技政策也将AI驱动科学研究列为重点方向。

跨学科检索会带入只在背景中提及AI、使用常规数值优化或自动微分的文献。筛选时需要核对AI是否实际承担了预测、设计、发现或实验任务，并保留判断依据。

本研究以2010—2026年Web of Science核心合集文献为对象，通过文献计量分析考察发文分布与主题演化，再结合重点文献，从科学任务、建模逻辑和科研流程三个方面分析AI参与科研的方式。


## 研究思路

不预设领域清单，而把 AI4S 拆成**方法、任务、领域三个同时成立的条件**，检索式据此分三条路径召回：

1. **显式表述**：标题、摘要中含 AI for science、AI4S 等自我标识
2. **方法 × 任务 × 领域**：AI 方法词、科研任务词、目标领域词在题录中同时出现
3. **SciML 与物理约束**：科学机器学习、PINN 等与方程、守恒律等约束共现

三条路径取并集，再限定年份、语言与文献类型。检索只负责召回，AI 是否实质承担科研任务由逐篇内容判断；结果按版本冻结，11,637 条候选最终收敛为 9,470 篇核心。
