# AI4Sdatabase：AI for Science 文献数据集

## 项目简介

AI4Sdatabase 是一项 AI4S 文献计量研究的配套数据集，整理人工智能参与科学研究的相关文献，用于分析研究主题的演化，以及 AI 介入科研的具体方式。

本研究以2010—2026年 Web of Science 核心合集文献为对象，关注 AI 在数学、自然科学和工程科学问题求解中的应用。仓库公开文献检索式、词项来源、筛选依据和基本统计，便于读者了解数据集的构建过程，并在相关研究中查阅和使用。

## 研究背景与思路

人工智能已被用于数学发现、材料与分子设计、蛋白质结构预测、方程求解和自主实验等科研任务。研究者既关注这些方法能够解决什么问题，也关注它们如何改变建模、实验和发现的过程。

梳理这些研究，首先需要明确文献范围。跨学科检索会带入一般科研辅助、常规数值计算，以及只在背景中提及 AI 的文章。本研究以 AI 是否实际承担具体科学任务为筛选依据，确定用于分析的文献样本。

论文结合文献计量分析与重点文献内容分析。文献计量部分考察发文趋势、学科与机构分布，以及研究主题随时间的变化；内容分析部分进一步阅读重点文献，从科学任务、建模逻辑和科研流程三个方面，比较 AI 在不同研究中的作用。

## 如何使用

- **直接检索文献**：将完整检索式复制到 Web of Science 核心合集的高级检索中，获取相应范围的候选文献，再根据研究目的开展筛选。
- **借鉴检索设计**：参考本研究将 AI 方法、科研任务和科学领域相结合的思路，设计自己的检索方案。
- **调整和完善检索式**：结合词项来源及筛选中发现的问题，补充领域术语、调整任务表达，或修改年份、语言和文献类型等条件，使检索式适合具体研究。
- **参考筛选与分析方法**：查阅各轮剔除依据和描述性统计，为同类研究的数据整理与分析提供参考。
