# AI4S-database：AI for Science 文献数据集

本研究关注人工智能如何参与科学研究，通过文献计量分析考察AI4S的研究格局与主题演化，并结合重点文献，从科学任务、建模逻辑和科研流程三个维度分析AI介入科研的方式。

## 研究背景

人工智能正在从科研的辅助工具转变为科学发现过程的参与者。近十年，AI 方法在数学猜想与符号推理、材料与分子设计、蛋白质结构预测、方程发现、自主实验等方向持续产出标志性成果；与此同时，主要国家的科技政策也先后把 AI 驱动的科学研究列为重点方向，"AI for Science" 由此成为科研组织和科技政策的重要议题。

但 AI4S 至今没有统一、可操作的边界。研究文献中，"仅在背景提及 AI""把常规数值优化或自动微分当作 AI 参与"与"AI 实质承担了预测、设计、发现或实验任务"混杂在一起；跨学科检索又会带入大量相邻领域的非目标文献。因此，**如何界定 AI4S、如何让样本可逐篇复核**，是这类计量研究首先要解决的问题。

本研究以 2010—2026 年 Web of Science 核心合集文献为对象，考察 AI 实质参与数学、自然科学与工程科学问题求解的**演进路径与科研介入方式**，采用文献计量与重点文献内容分析相结合的方法。本仓库是这项研究的数据开源，希望能够为相似的研究提供可借鉴的数据集合，以及检索式的设计逻辑借鉴
