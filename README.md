# AI4S 论文配套数据集

人工智能正在参与科学研究中的预测、模拟、设计与发现。本研究围绕AI4S（Artificial Intelligence for Science）的主题演化与科研介入方式展开，关注相关研究的发展格局、主题变化及AI在具体科学任务中的作用。

论文采用文献计量分析与重点文献内容分析相结合的思路：通过文献计量考察研究分布与主题演化，再从科学任务、建模逻辑和科研流程三个维度分析AI参与科研的方式。本仓库提供论文配套文献数据集的检索说明与基本统计。

## 文档说明

- **[检索词文档](检索词.md)**：介绍最终采用的WoS检索式、字段与范围设置，以及词项的政策、学科和文献来源。
- **[检索结果文档](检索结果.md)**：介绍数据规模，以及核心样本的年度、学科类别和来源期刊分布。
